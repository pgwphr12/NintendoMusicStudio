# Nintendo Music Studio 1.6.2-3 테스트본

## 1.6.2-3: NES ROM 음악 선택 추가

**.nes 파일을 열면 곡 목록으로 바로 재생**합니다. 이번 지원은 Super Mario Bros.1 사운드 코드를 사용하는 **NROM32 프로그램49종**이며 파일명이 아닌 전체32KiB PRG 크기/CRC로 확인합니다. 세계판·유럽Rev0A·한국어판과 검증한 일부 수정 ROM을 포함합니다. 음악 코드가 비슷하다는 것만으로 임의 ROM을 성공 처리하지 않습니다. NES2.0/트레이너/다른 매퍼·미등록 프로그램은 아직 미지원입니다.

원본6502 음악 드라이버와 데이터를 기존 NES APU 코어에서 실행하는 메모리 전용 어댑터입니다. 게임 시작 부분의 메모리 복사본에 자체 호출 코드를 넣으며 원본 ROM, 음악 부분, 세이브는 쓰지 않습니다. 그래픽은 사용하지 않으므로 지원 프로그램이 동일한 CHR 그림 변경본도 처리합니다. 원본14개 Area/Event 큐 명령을 표시하며 별칭·징글을 포함하고 정지 명령은 뺍니다. 기본4채널을 유지하며 Ground/Water의 실제4011 DAC 변화를 DMC 채널로 처음부터 표시합니다. DPCM 샘플을 추출했다는 의미가 아닙니다.

NTSC/PAL 주기는 등록한 원본 사운드 계열을 따릅니다. 곡 길이/모든 게임 상황/하드웨어와 완전히 같은 소리·타이밍은 보장하지 않으며 임의 게임을 지원하는 전체 NES 에뮬레이터도 아닙니다. 새 NES ROM 경로의 짧은 탐색은 원래 상태를 재생해 복원합니다. 긴 탐색은 기존 코어의 빠른 탐색과 최대1초의 실제 오디오 복원을 함께 사용합니다. 기존 GBA13프로필과 음악 파일 재생은 유지합니다. 모든 기종 ROM 지원은 진행 중인 장기 목표입니다.

## 1.6.2-2 GBA 지원 기록

같은 플레이어에서 .gba를 열어 Tracks 및 이전/다음으로 음악을 고릅니다. 원본 ROM 음악 드라이버를 실행하며 파일을 수정하거나 사용자 게임/세이브를 실행하지 않습니다.

| 게임 | 검증된 판본 수 | 원본 곡 ID 항목 수 |
|---|---:|---:|
| Super Mario Advance1 |4|319/321|
| Super Mario Advance2 |2(미국·유럽)|48|
| Super Mario Advance3 |2(미국·유럽)|40|
| Super Mario Advance4 |5(일본·미국·유럽·리비전/패치)|57|

총13개 크기/CRC 일치 프로필만 지원합니다.2·3·4편은1편의m4a와 다른 Nintendo 드라이버이므로 별도 초기화·곡 선택·프레임 갱신을 연결했습니다. 곡 번호 표의 원래 플래그·별칭을 보존하고, 모르는 시퀀서 채널 수나 제목은 만들지 않습니다. 기본 선택은2·3·4편Song0,1편Song170입니다.6개 하드웨어 채널4PSG+PCM A/B이며 개별 PCM 악기 분리는 아직 없습니다. 전체 ROM 지원은 장기 목표로, 목록 밖 판본/다른 게임/기종은 여전히 미지원입니다. 이전 테스트 기록의 제한은 해당 버전 기준입니다.

테스트본 표기는1.6.2-3이며 다음 수정은1.6.2-4처럼 끝 번호만 바꿉니다. 정식 배포본은1.6.2입니다.

이번 파일은 테스트본입니다. 사용자가 “배포본”이라고 명시한 경우에만 배포용으로 준비합니다.

## 1.6.2-1 첫 구현 기록

**파일 열기에서 .gba를 선택**하면 같은 플레이어에서 Tracks 목록과 이전/다음으로 ROM의 곡을 재생합니다. 첫 지원 범위는 로컬 검증한 **슈퍼 마리오 어드밴스1**의4개 판본(CRC32 c95824c4 /69924cbd /1e4c6d6a /b993b92f)입니다. 일본판319개, 나머지321개 실제 곡 ID를 표시하며 효과음도 포함됩니다. 제목·길이 메타데이터는 없어 Song번호로 표시하고, 시작곡은 Song170입니다. 다른 게임/수정본/기종 ROM은 지원하지 않는다는 오류를 표시합니다.

음악·악기를 추측하거나 MIDI로 바꾸지 않고 **ROM 안의 원래 m4a 드라이버**를 기존 GBA 에뮬레이터에서 실행합니다. 재생·탐색·반복 시작·파형·채널 음량/음소거를 공유합니다. 이번 ROM 경로는 Pulse1/2, Wave, Noise, PCM A/B의6개 하드웨어 채널이며 PCM 악기별 분리는 아직 연결하지 않았습니다. 기존 GSF의 개별 PCM 경로는 유지합니다. 원본은 읽기만 하며 메모리 복사본의 시작 분기와 자체 부트스트랩으로 음악만 호출합니다. 게임 실행·세이브 접근·BIOS 파일·추출 파일 생성은 없습니다. 원본 곡의 정확한 소리/실기 청감 동등성이나 모든 ROM 지원을 보장하지 않습니다.

Windows용 게임 음악·일반 오디오 플레이어입니다. 음악 재생과 채널별 파형·음량·음소거를 한 프로그램에서 제공합니다.

## 1.6.1h 핫픽스

- **VirtualMIDISynth가 없는 PC는 Windows 기본 음색만 사용**합니다. 예전에 저장한 SF2 경로나 외부 MIDI 출력 설정이 남아 있어도 이번 실행에서는 사용하지 않습니다. 기존 선택 파일은 지우지 않아 설치된 PC에서 다시 사용할 수 있습니다.
- 하단 음색 버튼을 기존 크기/위치의 **Windows 기본** 회색 비활성 표시로 고정합니다. 클릭과 F8은 메뉴를 열지 않으며 SF2 가져오기·수동 선택·자동 반영·외부 직접 출력이 제한됩니다. 기본 음색의 재생·채널별 파형·플레이어 효과는 유지합니다.
- 설치된 PC에서는 기존 사운드폰트/외부 출력 기능을 유지합니다. 설치 여부는 실행 시 MIDI 장치/실행 파일 존재로 확인하며, 프로그램이 실행 중이지 않은 설치도 구분합니다. 설치/제거 뒤에는 플레이어를 다시 실행하세요.

- **실시간 음색 반영**: 가져오기 후 VMS에서 SF2를 바꾸고 적용/확인으로 저장하면 약 1초 내 감지합니다. 재생 위치·일시정지·전체/채널 음량·음소거를 유지하며, 실패하면 기존 음색을 유지합니다. 큰 SF2 로딩/복잡한 MIDI 위치 복원에는 추가 시간이 들고 교체 중 잠시 멈출 수 있습니다.
- **MIDI 이름**: Channel 1, Channel 2처럼 간단한 영어 이름을 사용합니다. 실제 MIDI 채널 번호를 유지하며 드럼 채널도 Channel 10으로 표시합니다. 이전 MIDI 이름으로 저장된 음량·음소거는 이어받고, 새 이름으로 저장된 설정이 있으면 우선합니다.
- **녹화뷰 이름**: 긴 채널 이름을 각 칸의 폭에 맞춰 전체 표시합니다.

VMS와 같은 SF2를 자체 TinySoundFont에서 합성하며 VMS/BASS의 출력 자체나 모든 효과·적층을 재현하지 않습니다. 외부 MIDI 직접 출력은 채널별 PCM 파형을 제공하지 않습니다. 기존16M 이벤트/64MB MIDI 입력/2시간 MIDI 길이/256MB 음색 파일/채널당256동시 음성 등의 범위와 각 게임 형식의 제한은 유지합니다. 음악·ROM·사운드폰트는 배포본에 넣지 않습니다. 과거 핫픽스 기록은 아래에 보존합니다.

## 1.5.12 변경 사항

- **F8**에서 `Windows 기본 MIDI 출력 장치`, `내부 합성 · Windows 기본 음색`, `내부 합성 · SF2/DLS`를 선택합니다. 선택한 사운드폰트는 내부 합성으로 사용합니다. 출력 모드를 바꾸면 현재 MIDI는 처음부터 다시 시작합니다.

- MIDI 호환성: **RIFF/RMID로 감싼 SMF**, 선언된 트랙 경계가 온전하나 종료 표식이 없는 곡, 메타데이터 사이 running status를 처리합니다. 없는 뱅크/음색은 내부 합성에서 GM의 같은 음색 또는 음색 파일의 첫 프리셋으로 대체하여 재생 오류를 줄였습니다. 원래 없는 악기의 완전한 음색 재현을 뜻하지 않습니다. 장치 출력에서는 제조사 SysEx도 전달합니다.

문제 MIDI 파일이 아직 제공되지 않아 사용자가 겪은 개별 오류의 해결 여부는 확인 전입니다. SMF format2(독립 시퀀스), 손상된 이벤트/트랙,2시간 초과 곡은 여전히 지원하지 않습니다. 장치 변경·재생 제어는 자체 시험 출력으로 검사했으며, 모든 외부 MIDI 드라이버의 실제 소리/지연을 검증한 것은 아닙니다.

## 1.5.10 변경 사항

- **ES5506을 32개 개별 음성 채널로 분리**했습니다. 재합성한 가짜 악기 트랙이 아니라 코어의 실제 음성별 출력 기여분입니다. 음성마다 파형·음량·음소거를 조절할 수 있습니다.
- 음성 합산에 속하지 않는 직접 버스 출력은 별도의 **ES5506 BUS RESIDUAL**로 보존합니다. 평소에는 무음일 수 있으며, 이를 특정 악기로 오인해 나누지 않습니다. 코어의 포화·직렬 출력 정밀도·이전 프레임 지연과 기존 믹스/보간을 유지합니다. 음성은 영구적인 악기 이름이 아닌 재사용되는 슬롯입니다.
- 이전 `ES5506 MIX`에 저장한 음량·음소거는 새 채널의 초기값으로 이어받으며, 이미 저장한 개별 채널 설정이 있으면 그 값을 우선합니다.
- 다른 칩과 함께32채널을 넘어도 개별 음소거가 동작하도록64비트로 확장했습니다. 채널 수에 따라2·3·4열로 배치합니다. 최대64개까지 표시하며 기본 화면/녹화뷰의 칸 경계와 이름 위치를 유지합니다.
- **AY8930 VGM 재생과3채널 파형**을 추가했습니다. 확장 모드·듀티·독립 엔벌로프·노이즈 마스크를 지원하는 Furnace의 BSD3 코어를 사용합니다. AY8910으로 바꿔 재생하는 방식이 아닙니다. VGM stereo mask도 반영합니다.
- MIDI·Windows 기본 음색·SF2/DLS 선택과20개 확장자 등록 기능은 그대로 포함합니다.

AY8930은 단일 칩, VGM chip type3 및 지원 플래그/클록 범위에 한정됩니다. 다른 AY/YM 모델·듀얼 AY·YM2203 SSG는 이번 추가 범위가 아닙니다. 코어 자체의 AY8930 아날로그 볼륨 특성은 근사이며 모든 실물 하드웨어와 동일한 소리를 보장하지 않습니다. 합성기의 DC 성분은 고정20Hz DC 차단을 거칩니다.

## 1.5.9 변경 사항

- MIDI(.mid/.midi, SMF format0/1) 재생과 사용 중인 MIDI 채널별 실제 합성 파형을 추가했습니다. 템포·악기 변경, CC 음량·팬·서스테인·피치 벤드를 처리합니다.
- 기본 음색은 Windows DirectMusic의 `GMFilePath` 설정을 읽고, 설정이 없으면 Windows의 `gm.dls`를 사용합니다. 음색 데이터는 로컬에서 읽으며 배포본에 넣지 않습니다.
- **MIDI 음색(F8)** 버튼에서 **SF2/DLS 파일 선택** 또는 **Windows 기본 음색**을 선택할 수 있습니다. 선택은 다음 실행에도 유지하며, 재생 중인 MIDI에서 바꾸면 처음부터 새 음색으로 재생합니다.
- 일반 오디오 4종과 MID/MIDI를 포함한 **20개 확장자**를 기본 앱 등록 목록에 포함합니다. 이전에 등록을 허용했다면 새 목록도 갱신합니다. 기존 Windows 기본 앱 선택은 임의로 변경하지 않습니다.

## # MIDI와 사운드폰트 지원 범위

MIDI는 내부 TinySoundFont 합성기를 통해 기존 음량·채널 음소거·피치·속도·반향·파형·반복·탐색에 연결됩니다. **Windows 기본 음색 파일을 사용하지만 Microsoft GS Wavetable Synth/MIDI Mapper 자체의 소리와 동일하다는 의미는 아닙니다.** VirtualMIDISynth 같은 다른 프로그램의 사운드폰트 설정을 자동으로 가져오지는 않습니다. 원하는 SF2는 F8에서 선택하세요.

지원 음색: **PCM SF2, DLS1의 모노 PCM8/16 샘플**. General MIDI 구성의 음색 파일을 권장합니다. SF3/SFZ, DLS2/압축 DLS, MIDI format2는 지원하지 않습니다. SF2의 사용자 모듈레이터, 애프터터치, 제조사 전용 SysEx 및 일부 DLS 연결 효과는 제한됩니다. 원본 Windows 신디사이저를 완전히 재현하는 기능은 아닙니다. MIDI 길이는 최대2시간이며 파일 끝에2초의 릴리스 구간을 둡니다. 탐색은 합성을 재실행하므로 긴 곡의 뒷부분 탐색에는 시간이 걸릴 수 있습니다.

사용자의 MIDI·사운드폰트와 Windows 음색 파일은 재배포 ZIP에 포함하지 않습니다. 음악과 음색 파일의 권리는 프로그램 라이선스와 별개입니다.

## 1.5.8 변경 사항

- MP3·WAV·OGG·FLAC를 열면 재생 버튼을 누르지 않아도 바로 시작하도록 수정했습니다. 파일 열기·끌어놓기·최초 실행의 공통 열기 경로에 적용됩니다.
- 다음 곡으로 넘어가는 자동재생 설정과 수동 일시정지는 그대로 유지합니다.

## 1.5.7 변경 사항

- 녹화뷰 파형 오른쪽을 화면 끝이 아닌 각 채널 칸의 경계에 맞췄습니다. 바깥쪽 여백과 두 열 사이 간격을 유지합니다.
- 녹화뷰 채널 이름을 위로 올리고 이름 표시 영역의 높이를 줄여 아래로 처져 보이지 않도록 조정했습니다.
- 1.5.6의 전체화면 반복 재생 수정과 기존 음원 재생 방식은 유지합니다.

## 1.5.6 변경 사항

- 전체화면에서 반복·다음 곡 이동 검사가 UI 타이머에만 의존하지 않도록 수정했습니다. 화면 갱신 메시지에서도 끝을 확인하여 F9 전환이나 전체화면 해제 없이 반복하도록 보완했습니다.
- 녹화뷰 파형을 오른쪽 화면 끝까지 확장했습니다. 두 열일 때도 각 열의 끝까지 표시하며, 이름은 파형 위에서 읽을 수 있습니다. 일반 화면 여백은 유지합니다.
- 타이머 전달을 차단한 자체 시험에서 F11 전체화면·F9 녹화뷰·일반 창 복귀·재진입 반복 및 DS 자동 다음 곡 이동을 확인했습니다. 기존 오디오·MP3 판별 수정은 유지합니다.

## 1.5.5 변경 사항

- 앞부분 표식이 일반적이지 않아도 실제 디코더가 읽을 수 있는 MP3를 열도록 판별을 수정했습니다. 제공 폴더의 mission.mp3 13개에서 열기·재생·탐색·음소거·재시작을 확인했습니다. 파일 자체를 변환하거나 수정하지 않습니다.
- 일반 오디오는 파일에 적힌 예상 길이 대신 실제 디코더의 끝을 기준으로 반복합니다. 길이 정보가 실제 음원보다 긴 경우 무음으로 기다리던 문제를 보완했습니다. 반복을 끈 상태에서는 끝난 뒤에도 표시 시계·파형이 계속 진행됩니다.
- 녹화뷰 파형을 왼쪽 채널 이름 영역까지 확장하고 이름은 파형 위에 표시합니다. 일반 화면의 파형 위치와 음량 조작은 유지합니다.
- GBA·DS·N64·BCSTM/BCWAV·기본/확장 VGM/VGZ 반복을 시험했고 실제 GBA·DS·N64의 대표 곡에서도 버튼 반복을 확인했습니다. 모든 파일의 루프 위치를 자동으로 추측한다는 의미는 아닙니다.

# # 일반 음악 파형 보기

MP3·WAV·OGG(Vorbis)·FLAC를 열거나 창으로 끌어 놓으면 재생하면서 파형을 볼 수 있습니다. 스테레오는 **PCM LEFT / PCM RIGHT**, 모노는 **PCM MONO**로 표시합니다. 기존 재생·일시정지·탐색·반복·채널 음량·음소거·피치·속도·녹화뷰를 그대로 사용합니다. 폴더의 일반 음악 형식을 섞어서 이전/다음·자동재생할 수 있습니다.

파일 전체를 미리 PCM으로 변환하지 않고 읽으면서 재생합니다. 별도 FFmpeg·코덱 설치가 필요하지 않습니다.2채널을 넘는 입력은 스테레오로 합쳐 표시하며, 보컬·악기별 분리 기능은 아닙니다. Ogg Opus·M4A/AAC는 이번 버전의 지원 대상이 아닙니다. 한 파일24시간까지 지원합니다. 기존 게임 음원 재생 및1.5.3의 ES5506 변환 수정도 유지합니다. 원본 음악과 기존 설정은 덮어쓰지 않습니다.

# # 실행

Windows10/11 64비트 환경에서 ZIP을 새 폴더에 풀고 **NintendoMusicStudio.exe**를 실행하세요. 별도 DLL을 같은 폴더에 둘 필요가 없습니다. 설치나 Python·FFmpeg·Visual Studio 없이 실행합니다. 음악 파일은 사용자가 직접 준비해야 합니다. 음악과 연결되는 보조 라이브러리는 원래 폴더 구조로 함께 두세요.

이 프로그램은 Nintendo와 제휴·승인 관계가 없는 비공식 프로그램입니다. 실행 파일에는 전자서명을 적용하지 않았습니다.

VGM에는 기존 SMS/Mega Drive 경로와 추가 YM2612/YM3812/MSM6295/K051649/ES5506 경로가 있습니다. **모든 칩·조합을 지원하지는 않습니다.** 지원하지 않는 조합은 오류로 알립니다. ES5506은 칩 전체 MIX 한 줄로 표시합니다. 작곡·편집·프로젝트 저장·WAV 내보내기는 포함하지 않습니다.

GBA PCM VOICE는 재생 중 음성 슬롯이며 영구적인 악기 이름이나 MIDI 트랙이 아닙니다. 모든 GBA 드라이버의 개별 음성 분리가 완료된 것은 아닙니다. 사용하지 않는 PSG 채널은 지원되는 관측 범위에서 숨깁니다. 채널 파형은 원 디코더 신호 기준이며, 큰 피치·속도 변경은 음색·타격음을 변화시킬 수 있습니다.

# # 기존 설정과 업그레이드

압축은 이전 버전과 다른 폴더에 푸세요. 기존 프로그램을 자동으로 종료하거나 덮어쓰지 않습니다. 호환성을 위해 `%LOCALAPPDATA%/GameMusicPlayer/settings.ini`의 설정 위치를 유지하므로 기존 음량·피치·속도 설정을 이어받습니다. 이것은 예전 내부 이름의 저장 경로이며, 공개 프로그램의 표시 이름과 실행 파일은 Nintendo Music Studio입니다. 이전 Studio 설정이나 원본 음악을 변환·삭제하지 않습니다.
