# Version policy

Stable: X.Y.Z, without iteration/beta; current1.6.2. A test build is the default unless the user explicitly requests a distribution build. Future tests use X.Y.Z-N beta in title/About/resource string/RELEASE.json, e.g.1.6.3-1 beta or1.6.3-10 beta. Filename token uses hyphen:1.6.3-1-beta. Numeric Windows version uses X,Y,Z,N. Stable uses X,Y,Z,0. Keep old artifacts intact; urgent fixes retain the user-requested h suffix when applicable. A stable package is not automatically uploaded externally.
