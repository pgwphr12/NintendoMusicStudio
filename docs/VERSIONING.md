# Version policy

Latest user correction: stable X.Y.Z; future tests X.Y.Z-beta N (e.g.1.6.3-beta 1 /1.6.3-beta 2). Filename token X.Y.Z-beta-N. Numeric Windows version X,Y,Z,N. Test is the default unless a distribution build is explicitly requested. Current test1.6.3-beta 2, next1.6.3-beta 3; stable1.6.2 is preserved. Stable numeric version X,Y,Z,0. Keep old artifacts/labels unchanged; urgent stable hotfixes retain h when applicable. No automatic external upload. This supersedes the previous X.Y.Z-N beta rule for future artifacts.
