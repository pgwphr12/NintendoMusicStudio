# Nintendo Music Studio 1.5

Windows용 게임 음악 플레이어입니다. 음악 재생과 채널별 파형·음량·음소거를 한 프로그램에서 제공합니다. 기존 내부 시험본의 개선 사항과1.4.18 VGM 음높이·음량 수정이 포함된 공개용 배포본입니다. 편집·작곡 프로그램은 아닙니다.

## 실행

Windows10/11 64비트 환경에서 ZIP을 새 폴더에 풀고 **NintendoMusicStudio.exe**를 실행하세요. **gme.dll**을 같은 폴더에 두세요. 설치나 Python·FFmpeg·Visual Studio 없이 실행합니다. 음악 파일은 사용자가 직접 준비해야 합니다. 음악과 연결되는 보조 라이브러리는 원래 폴더 구조로 함께 두세요.

이 프로그램은 Nintendo와 제휴·승인 관계가 없는 비공식 프로그램입니다. 실행 파일에는 전자서명을 적용하지 않았습니다.

## 기능

- 파일 열기·끌어 놓기, 내부 트랙 선택, 폴더 이전/다음·자동재생·반복
- 영어 채널 이름, 채널별 파형·음소거·0–200% 음량, 모든 채널 음량 일괄 조절
- 피치와 속도를 각각0.50–2.00배로 조절; 기본 단위0.01, 선택 단위0.10
- 반향 강도76%·잔향3.0초 기본값; 켜기/끄기 별도
- 녹화뷰: 음량 조절부 숨김과 큰 재생 시계
- 본창 조작을 막지 않는 F1/플레이어 정보 창
- 44.1kHz 이상에서 출력 샘플레이트와 별개로 모니터 주사율을 따르는 파형 표시

## 지원 범위

| 계열 | 입력 형식 |
|---|---|
| NES/Famicom | NSF, NSFE |
| Super NES | SPC |
| Game Boy | GBS |
| Game Boy Advance | GSF, MINIGSF |
| Nintendo DS | 2SF, MINI2SF |
| Nintendo64 | USF, MINIUSF |
| Nintendo3DS 오디오 | BCSTM, BCWAV |
| 칩 로그 | VGM, VGZ |

VGM에는 기존 SMS/Mega Drive 경로와 추가 YM2612/YM3812/MSM6295/K051649/ES5506 경로가 있습니다. **모든 칩·조합을 지원하지는 않습니다.** 지원하지 않는 조합은 오류로 알립니다. ES5506은 칩 전체 MIX 한 줄로 표시합니다. MP3 재생, 작곡·편집·프로젝트 저장·WAV 내보내기는 포함하지 않습니다.

GBA PCM VOICE는 재생 중 음성 슬롯이며 영구적인 악기 이름이나 MIDI 트랙이 아닙니다. 모든 GBA 드라이버의 개별 음성 분리가 완료된 것은 아닙니다. 사용하지 않는 PSG 채널은 지원되는 관측 범위에서 숨깁니다. 채널 파형은 원 디코더 신호 기준이며, 큰 피치·속도 변경은 음색·타격음을 변화시킬 수 있습니다.

## 기존 설정과 업그레이드

압축은 이전 버전과 다른 폴더에 푸세요. 기존 프로그램을 자동으로 종료하거나 덮어쓰지 않습니다. 호환성을 위해 `%LOCALAPPDATA%/GameMusicPlayer/settings.ini`의 설정 위치를 유지하므로 기존 음량·피치·속도 설정을 이어받습니다. 이것은 예전 내부 이름의 저장 경로이며, 공개 프로그램의 표시 이름과 실행 파일은 Nintendo Music Studio입니다. 이전 Studio 설정이나 원본 음악을 변환·삭제하지 않습니다.

기본 앱 등록은 안내창/F10에서 선택합니다. 지원 확장자를 등록한 뒤 Windows 설정에서 직접 기본 앱을 선택하며, 기존 기본 앱을 강제로 바꾸지 않습니다.
