## 최신 테스트본 1.6.3-beta 7

## 베타 6 부드러움 개선

파형 정렬·이력 복사 부담을 줄이고, 채널 이름은 투명한 그리기 결과를 재사용합니다. 새 음의 파형과 표시 크기는 화면 갱신 시간에 맞춰 짧게 보간합니다. 소리에는 영향을 주지 않습니다. 1080p 자체 시험에서 이전판보다 그리기 시간을 줄였으며 실제 주사율 체감은 환경에 따라 다릅니다. 버전은 사용자 요청대로 베타 6 유지.

## 베타 6 정정본 (2026-11-10)

파형의 옆 흐름/떨림을 줄이고, 표준 MP2K GBA 곡에서 쓰지 않는 PSG 기본 채널을 곡 명령 전체 기준으로 숨깁니다. PCM은 유지합니다. 모든 채널 표시 옵션도 포함합니다. 지원하지 않는 GBA 명령/드라이버는 잘못 숨기지 않도록 유지합니다.

# Nintendo Music Studio 1.6.2

Windows x64용 게임 음악·일반 오디오·MIDI 플레이어입니다. 이번 정식본은1.6.2-1~12 테스트의 안정화 내용을 통합하고 현재 곡의 혼합 채널 음량 유지 문제를 수정했습니다. [업데이트 목록](RELEASE-NOTES-1.6.2.md)

## 실행

ZIP을 풀고 **NintendoMusicStudio.exe**를 실행하세요. 별도 DLL 설치가 필요 없습니다. 기존 설정과 이전 실행본을 보존하며, 원본 음악과 ROM을 수정하지 않습니다.

## 주요 조작

- 파일 열기/드래그로 음악을 불러옵니다. 폴더 목록과 곡 선택·반복·탐색을 지원합니다.
- **F6**: 채널 파형/스펙트럼 전환. **F7**: 막대형·선형·가로흐름 선택창. 기본 종류는 가로흐름이며 저장된 선택을 복원합니다.
- **F9**: 녹화뷰와 별도 리모컨. **F11**: 전체화면. **F1**: 플레이어 정보.
- 모든 채널 음량을 저장하고 다음 곡에 우선 적용합니다. 현재 곡에서 개별 채널을 다르게 조절한 혼합 값은 정지·재생·탐색 중 유지됩니다. 음소거와 마스터는 별도입니다.
-20밴드 EQ는±20dB 정수/직접 입력을 지원합니다. 피치·속도·반향도 조절할 수 있습니다.

## 지원 범위

NSF/NSFE·SPC·GBS·GSF·2SF·USF·VGM/VGZ 등 게임 음악, 일반 오디오와 MIDI를 지원합니다. 코덱/칩/게임 드라이버별 지원 범위는 다르며 모든 파일의 재생을 보장하지 않습니다. 외부 MIDI 직접 출력은 내부 PCM 파형·효과와 별개입니다. 사용자/시스템 사운드폰트는 로컬에서 참조합니다.

ROM 직접 재생은 GBA13개 검증 프로필 및 SMB1 계열 NES NROM32 프로그램 지문49개에 한정됩니다. 마리오 어드밴스1~4의 PCM은 동적 음성 슬롯이며 고정 악기 트랙이 아닙니다. 모든 ROM의 음악을 직접 재생하는 기능은 아직 아닙니다. GB 호환 음원 모드는 GB CPU 실행과 AGB APU의 연결이며 GBA ARM/FIFO 실행으로 바꾸는 기능은 아닙니다.
